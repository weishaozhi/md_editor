## 复杂问题与解决方式

### 问题 1：children 始终渲染，无法收起

**现象**：点击 Chevron 图标后 `toggleFolder` 正确更新了 `expandedFolders: Set<number>`，但 `FileTree.tsx` 渲染子项时没有读取该状态，children 永远可见。

**根因**：[frontend/src/components/FileTree/FileTree.tsx:324](../frontend/src/components/FileTree/FileTree.tsx) 原条件：

```tsx
{item.is_folder && item.children.length > 0 && (
  <FileTree items={item.children} ... />
)}
```

缺 `isFolderExpanded(item.id)` 守卫——这是 § 12 修复的逻辑漏洞。

**解决方式**：在 `FileTree` 函数体顶部声明 `const { isFolderExpanded } = useFileStore()`，并在递归渲染处补齐守卫：

```tsx
const { isFolderExpanded } = useFileStore();

{item.is_folder && isFolderExpanded(item.id) && item.children.length > 0 && (
  <div className="ml-4 pl-2 border-l border-slate-200 dark:border-slate-700">
    <FileTree ... depth={depth + 1} />
  </div>
)}
```

### 问题 2：嵌套子项视觉未区分

**现象**：原代码递归渲染子 `FileTree`，但未加缩进和分组样式，文件夹内文件与外部文件视觉平级。

**根因**：缺 `depth` 参数与外层容器 div。

**解决方式**：
- `FileTreeProps` 新增 `depth?: number`（顶层默认 0）
- 递归调用时 `depth={depth + 1}`
- 子 `FileTree` 用 `<div className="ml-4 pl-2 border-l border-slate-200 dark:border-slate-700">` 包裹——左外边距 16px、内部留白 8px、左侧 1px 浅灰边框

### 问题 3：展开状态无法跨刷新保留

**现象**：刷新浏览器或重启前端后，所有文件夹回到默认收起状态，需重新逐个展开。

**根因**：`fileStore` 仅为内存中的 `Set<number>`，没有持久化层。

**解决方式**：参照 `authStore.ts` 的 `persist` 中间件模式：

```ts
export const useFileStore = create<FileState>()(
  persist(
    (set, get) => ({
      expandedFolders: new Set<number>(),
      toggleFolder: (folderId) => {
        const expanded = new Set(get().expandedFolders);
        expanded.has(folderId) ? expanded.delete(folderId) : expanded.add(folderId);
        set({ expandedFolders: expanded });
      },
      // ...
    }),
    {
      name: 'file-tree-storage',
      partialize: (state) => ({ expandedFolders: Array.from(state.expandedFolders) }),
      onRehydrateStorage: () => (state) => {
        if (state && Array.isArray(state.expandedFolders)) {
          state.expandedFolders = new Set(state.expandedFolders);
        }
      },
    },
  ),
);
```

要点：
- `Set<number>` 不能直接 JSON 序列化；`partialize` 把它转 `Array<number>` 写入 `localStorage`
- `onRehydrateStorage` 在水合时把 `Array<number>` 还原为 `Set<number>`，组件读 `isFolderExpanded` 时无需关心持久化细节
