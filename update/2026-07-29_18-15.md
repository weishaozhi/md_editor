## 复杂问题与解决方式

### 问题 1：拖拽放置区域未实现

**现象**：拖拽文件到文件夹上方时无视觉反馈，放开后文件未移动

**根因**：Row 组件只有 draggable 属性，没有实现 onDragOver/onDrop 事件处理器

**解决方式**：
- 在 Row 组件添加 onDragOver（阻止默认行为，设置 dropEffect）
- 添加 onDrop 事件解析 dataTransfer，调用 onDirectMove
- 修复 Chevron 按钮使用 onMouseDown 而非 onClick（避免被 onDrop 阻止）

### 问题 2：parent_id null 值处理

**现象**：将文件移回根目录时，API 无法区分"未传 parent_id"和"显式设为 null"

**根因**：FastAPI/Pydantic 的 Optional[int] 无法区分不传和传 null

**解决方式**：
- 前端使用字符串哨兵 `"__none__"` 表示根目录
- 后端 schema 支持 Union[int, str]
- 后端 API 解析：如果是 `"__none__"` 则设为 None

### 问题 3：嵌套文件夹创建被拒绝

**现象**：创建嵌套文件夹时返回 400 错误

**根因**：后端代码中有硬编码限制 `if file.is_folder and file.parent_id is not None`

**解决方式**：移除该限制，允许任意层级嵌套
