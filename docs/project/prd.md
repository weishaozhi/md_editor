## 1. 项目一句话描述

一个本地优先、可版本化、可多人协作的 Markdown 编辑工具，覆盖“打开 → 编辑 → 保存 → 回顾 → 回滚”的完整闭环。

## 3. 用户流程

### 3.1 主流程（已实现）

```
注册 → 登录 → 进入 Dashboard（文件树）
  └─ 新建文件 → 进入 EditorPage
       └─ 编辑 → 自动保存版本 → 版本面板查看历史 → 对比/回滚 → 导出 .md/.html
```

### 3.2 登录细节（验收必查）

| 场景 | 期望结果 |
|---|---|
| 输入正确账号密码 | 200 + JWT，跳转到 `/`（Dashboard），使用 `navigate('/', { replace: true })` |
| 输入错误密码 | 401，前端提示“用户名或密码错误”；**不锁定账号**，**不清空已填表单中的用户名** |
| 多次错误密码 | 仅做频控提示（不锁）；具体限频策略待定，见 `project_state.md` |
| 未登录访问受保护页 | 跳转 `/login`，登录成功后回到原页面 |
| Token 过期 | 拦截器拦截 → 清理 store → 跳 `/login` |
| 注册重复用户名 | 后端 4xx 响应，前端友好提示 |

## 4. 页面清单

| 路径 | 页面 | 鉴权 | 说明 |
|---|---|---|---|
| `/login` | LoginPage | 否 | 已登录则跳转 `/` |
| `/` | DashboardPage | 是 | 文件树 + 入口 |
| `/editor/:fileId` | EditorPage | 是 | 编辑 + 预览 + 版本面板 |
| `/settings` | SettingsPage | 是 | 用户偏好 |
| `*` | 404 → 自动跳转 | — | 已登录跳 `/`，未登录跳 `/login` |

## 5. 视觉与交互基线

> 本节为讨论锚点，最终风格在第一次定稿后由 [`arch.md` § UI 框架](./arch.md) 固化。

- **整体调性**：简约、信息密度适中；优先文字内容本身，而非装饰。
- **导航栏**：顶部水平 + 左侧文件树组合；用户头像 / 登出置于右上。
- **可选风格**（首版选择其一，后续统一）：
  1. **极简白底**：白底 + 灰阶 + 单一强调色，类 Notion 风格。
  2. **商务深色**：深底 + 高对比文字，类 Linear / VS Code 暗色。
  3. **类 GitHub**：左右双栏 + Markdown 渲染样式贴近 GitHub。
- **参考站候选**（任选其一作为锚点）：notion.so / obsidian.md / vscode.dev / github.com。

## 6. 验收标准（验收时逐项核对）

### 6.1 通用
- 启动链路：`backend/run.py` 起 FastAPI（`:8000`），`frontend npm run dev` 起 Vite（`:5173/5174`），脚本见 `backend/start.bat`。
- 所有 F1–F7 涉及的接口在 `docs/API.md` 中必须有契约。

### 6.2 登录
- 成功后跳转 `/`；失败有友好提示且不锁定。
- 刷新页面后已登录态保持；退出后立即失效。

### 6.3 编辑 / 版本
- 编辑内容 1s 节流自动保存；显式保存可生成命名版本。
- 版本列表按 `version_num` DESC 排序，附带时间与评论。
- 版本对比可看到行级 diff；点“恢复”回到该版本并创建新快照。

### 6.4 导出
- `.md` 下载内容与当前编辑器一致。
- `.html` 下载可直接在浏览器打开，中文文件名不乱码（RFC 5987）。

### 6.5 性能
- 首屏可交互时间（TTI）< 2s（本地，关闭缓存刷新）。
- 1k 行 Markdown 文档滚动同步无掉帧。

## 7. 非功能需求

| 维度 | 要求 |
|---|---|
| 安全 | JWT 鉴权；服务端对所有写入操作做授权；API Key 仅服务端持有；前端无敏感凭据 |
| 性能 | TTI < 2s；P95 接口响应 < 300ms（本地）；协作延迟 < 200ms |
| 可用性 | 单点失败（数据库）下，前端只读；UI 关键路径离线降级 |
| 成本 | 自用优先；上线需评估：域名 / 证书 / 对象存储 / CDN |
| 合规 | 用户数据本地存储 + 可选云端同步时需明示；不做支付、不收集支付数据 |
| 可观测 | 后端日志必须打印；关键路径含 INFO / WARN / ERROR 三档 |

## 8. 范围外

- 多人在线光标的冲突解决 CRDT/OT 细节（仅做基础广播，复杂合并后续讨论）。
- 移动端布局（仅保证桌面 ≥ 1280px 可用）。
- 第三方云同步（iCloud、Dropbox 等）。
- 富文本所见即所得编辑器（仅做 Markdown 编辑 + 预览）。
